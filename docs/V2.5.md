## Deploy Preview steps

1. Review the entire existing working tree, commit the intended files on v2, then push and open a PR against master without merging.
2. Keep master as Netlify's production branch. Use the existing project’s Deploy Preview with npm run build, .next, Node 22 and the automatic OpenNext adapter.
3. Enable form detection before a fresh preview deploy; confirm project-enquiry in the Forms dashboard.
4. Submit a clearly labelled test using an email controlled by the owner. Confirm every field in the dashboard and receipt of the configured notification.
5. Recheck all locales, project navigation, mobile contact, reduced motion, legal links and preview noindex on that preview.

Existing business-registration scope, host details and retention-policy confirmations still make `npm run check:production` exit 1. They are documented launch items, not failed preview-build checks. Resolve them and verify real form receipt before any later production promotion. See [LAUNCH.md](LAUNCH.md) for the full procedure.
